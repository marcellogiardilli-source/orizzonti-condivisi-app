# Orizzonti Condivisi – Vivere Viaggiando

App Android del gruppo **Vivere Viaggiando – Orizzonti Condivisi**: uscite in amicizia, viaggi di gruppo, racconti e strutture convenzionate.

## Scarica l'app

👉 **[Scarica l'ultima versione (APK)](https://github.com/marcellogiardilli-source/orizzonti-condivisi-app/releases/latest/download/OrizzontiCondivisi.apk)**

Apri il link dal telefono Android, scarica il file e toccalo per installarlo (la prima volta Android chiede di consentire l'installazione da questa origine).

Quando esce una nuova versione, l'app lo segnala da sola all'apertura e propone di aggiornarla.

Questo repository contiene solo l'app da scaricare e il file `versione.json` usato per il controllo degli aggiornamenti.
